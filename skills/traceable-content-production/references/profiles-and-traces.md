# 本地档案与追溯

## 存储位置

默认在当前内容工作区创建：

```text
.content-system/
├── .gitignore
├── user-preferences.md
├── accounts/
│   └── default.md
└── runs/
```

`.content-system/.gitignore` 默认内容为：

```gitignore
*
!.gitignore
```

这样私有档案和运行记录默认不进入 Git。不要把它们放进 Skill 目录。若当前目录不可写，使用当前会话配置并明确说明没有持久化；不得声称已经保存。

## 初始化

复制 [用户偏好模板](../assets/user-preferences-template.md) 和 [账号档案模板](../assets/account-template.md)。只在字段影响当前文章且无法可靠推断时询问，顺序优先为：

1. 目标读者；
2. 核心价值承诺；
3. 主要内容范围和常见类型；
4. 账号定位与已有表达偏好。

每次只问一个最高价值问题。用户已经在材料中提供的信息直接填写，不重复询问。

## 偏好更新

普通反馈先进入“待确认候选”，记录：候选内容、适用场景、不适用场景和依据。用户明确确认后才移入“已确认偏好”，并从待确认区删除。

只有文件实际写入并重新读取验证成功后，回复“已经保存”。失败时保留在本轮上下文并说明原因。

偏好是条件性默认值，不是固定比例。遇到不适配题材时保留其底层意图，例如“阅读顺畅”，但不机械套用叙事结构或降低证据强度。

## 运行记录

每次任务可在 `runs/` 保存一份简洁记录，至少包含：

- 日期与文章标识；
- 输入路线和原始材料位置或摘要；
- 使用的账号与已确认偏好；
- 事实、外部证据、编辑推演和虚构示例的归属；
- 状态变化与暂停原因；
- 用户确认；
- 最终稿位置或未生成原因。

不复制整段对话；只保存支持复核的结构化事实、依据、影响和行动。
